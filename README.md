# Python Learning Projects

Welcome to my Python learning repository!

This repository contains beginner-level Python projects I have built while developing my programming skills. Each project has helped me practise fundamental programming concepts and improve my problem-solving abilities.

## Projects

### 1. Basic Calculator

A simple calculator that accepts two numbers and an operator.

Features:

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero error handling

### 2. Word Guessing Game

A simple guessing game where the player tries to guess a predefined secret word within three attempts.

### 3. Mad Libs

A small interactive word game that collects user inputs, such as an animal, a verb, and a food, and uses them to generate a funny sentence.

### 4. Simple Story

A basic program demonstrating how variables and strings can be used to create and display a short story.

## Python Concepts Practised

- Variables and data types
- User input
- Type conversion
- Conditional statements
- While loops
- String concatenation
- Basic error handling

## Requirements

- Python 3
- No external libraries required

## Running the Projects

Download or clone this repository, navigate to its folder, and run any project using Python.

Example:

"python "A Basic Calculator.py""
